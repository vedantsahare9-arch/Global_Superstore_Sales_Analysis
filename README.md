# Project Overview
This project analyzes the Global Superstore 2016 dataset using Microsoft Excel. The objective is to clean the data, perform sales analysis, and create an interactive dashboard to help understand business performance and support better decision-making.

# Key Insights
- Technology category generated the highest sales.
- The West region recorded the best sales performance.
- Some sub-categories performed better than others.
- Sales varied across different customer segments.
# key Features
- Data Cleaning in Excel
- Pivot Tables
- Pivot Charts
- Interactive Dashboard
- KPI Cards (Sales, Profit, Orders)
- Slicers for easy filtering.
